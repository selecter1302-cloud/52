# Fushidara KO Android — 1.05.9 mobile r1

Download `Fushidara_KO_A33_v1.05.9_r1.zip`, extract it, and install the APK inside.

This distribution targets ARM64 Android 7.0+ and uses Godot 4.7.2 with OpenGL compatibility rendering. It includes touchscreen F2 and Esc controls and does not import existing Windows saves. APK signatures and packaged assets were verified. Physical Galaxy A33 5G testing has not been performed.

The ZIP is stored using Git LFS because it exceeds GitHub's 100 MiB limit for ordinary Git objects. The actual ZIP is uploaded to LFS storage. `SHA256SUMS` records its SHA-256.

This branch contains only distribution artifacts; development files remain separate.
